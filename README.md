# Currículum Interactivo

Este repositorio contiene una plantilla básica para un currículum interactivo (HTML/CSS/JS).

Cómo usar:
1. Abrir la carpeta en VS Code: code .
2. Editar contenido en index.html, css/styles.css y js/script.js con tus datos.
3. Para ver localmente se puede usar la extensión Live Server o abrir index.html en el navegador.

Control de versiones:
- Ya se inicializó un repositorio Git local y se creó el primer commit. Para subir a GitHub crea un repo en GitHub y sigue estas instrucciones:
  git remote add origin https://github.com/tu_usuario/nombre_repo.git
  git branch -M main
  git push -u origin main

Publicación (opcional):
- Para publicar como sitio web estático se recomienda GitHub Pages (Settings → Pages) o usar gh-pages.
